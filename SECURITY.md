# Security reporting

Do not post credentials, private source or user data in public issues. For a suspected vulnerability, use the repository's private vulnerability reporting feature when enabled. If it is not enabled, ask a maintainer for a private reporting channel without publishing exploitation details or private inputs.

Keep PHP and the host operating system patched independently of this utility. The tool changes compatibility code; it does not establish that a legacy forum is secure.

Never install this repository as a web application. The CLI worker refuses HTTP execution. Keep full backups and diagnostic reports outside public document roots and public repositories.
