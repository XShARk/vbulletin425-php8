# Contributing

Report the utility version, PHP version, operating system, command and redacted error. Supply a minimal example written from scratch. Do not upload vendor archives, source files, database exports, license identifiers, secrets or real user content.

New rules need a regression test for their intended change and for surrounding constructs that must remain unchanged. Preserve source bytes and original encodings. Unknown vendor fingerprints require private verification with a licensed copy; never add full input files to this repository.

Run the Python and PHP suites and the release checker. Changes should preserve dry-run behaviour, backup integrity, custom-file refusal, idempotence and guarded restore. Do not add telemetry, automatic downloads or automatic production deployments.
